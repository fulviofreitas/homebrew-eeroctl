# Homebrew Tap: eeroctl

Homebrew formulae for [eeroctl](https://github.com/fulviofreitas/eeroctl) - the command-line interface for managing Eero mesh Wi-Fi networks.

## Installation

```bash
brew install fulviofreitas/eeroctl/eeroctl
```

## Upgrade

```bash
brew upgrade eeroctl
```

## Usage

```bash
eero --help
eero auth login
eero network list
eero device list
```
